## Short description

Control the selected Codex task and open common Codex views from Stream Deck.

## Full description

Codex Controls puts the next-turn settings of your selected Codex task on
Stream Deck. Use a key to set one model or thinking level. Add more values to
cycle through them in your chosen order.

Each setting key shows the current value and the value that the next press will
set. For a local task, the Model action changes the model, the Thinking action
changes the thinking level, and the Preset action changes both values. The
Single Preset action sets one preset and dims while the task uses other values.
The Shortcut action opens one selected Review, Terminal, Browser, Files, or
Side chat view.

Codex Controls detects local and remote tasks through Codex desktop. It shows
remote task values, but this release does not change them. You do not need to
add host settings to the plug-in.

Choose from 16 included color presets or save your own shared color presets.
Text fits the key by default. You can also show the title, hide the next value
on setting keys, and set the text size.

A local change applies to the selected task's next turn. It does not change a
turn that is already in progress.

## Feature list

- Model, Thinking, combined Preset, Single Preset, and Shortcut actions.
- Direct set with one value.
- Ordered cycling with two or more values.
- One selected command on each Shortcut key.
- Current and next values on each setting key.
- Automatic local and remote task detection.
- 16 included color presets.
- Shared custom color presets.
- Text that fits the key, with optional title and text sizes.
- Adjustable next-value option on setting keys.

## Privacy statement

Codex Controls has no analytics and no advertising. It communicates with Codex
desktop. It does not send task content to the plug-in author.
